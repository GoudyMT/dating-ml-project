# Dating Website Compatibility Prediction

This project uses the OkCupid dataset to predict user compatibility (binary classification) using demographic, preference, and essay data. It leverages XGBoost, NLP (TF-IDF and VADER), SHAP for interpretation, and advanced techniques like PCA and SMOTE to achieve high accuracy.

## Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/YourUsername/dating_ml_project.git
   ```
2. Create and activate a virtual environment:
   ```bash
   python -m venv venv
   .\venv\Scripts\Activate.ps1  # Windows
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run Jupyter Notebook:
   ```bash
   jupyter notebook
   ```
